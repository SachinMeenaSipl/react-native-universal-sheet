# Recipes

Complete examples you can paste into a screen. Each assumes `<NativeSheetProvider>` is already at the root ([Quick start](/guide/quick-start)).

| Recipe | Shows |
| --- | --- |
| [Filter sheet](/recipes/filter-sheet) | Two snap points, local state, apply on close |
| [Form with keyboard](/recipes/form-with-keyboard) | Inputs in a sheet, content-sized, validation |
| [Confirm dialog](/recipes/confirm-dialog) | `presentAlert` wrapped in a promise |
| [Toasts & notifications](/recipes/toast-notifications) | A tiny toast helper, snackbar with undo, top banner |
| [Multi-step checkout](/recipes/checkout-flow) | Stacked sheets, `replace`, `dismissAll` |
| [Named sheets](/recipes/named-sheets) | A typed registry opened from anywhere |
| [React Navigation](/recipes/react-navigation) | Provider placement, closing sheets on navigation |
